AI API CMD 코드


파이썬 설치 돼있는지 확인
python --version

//만약 버전이 안 뜬다면 설치가 안돼있는 것
	https://www.python.org 들어가서 3.12.xx 윈도우 64비트 버전 다운로드
	+) Add Python to Path 체크 

프로젝트 폴더 생성
mkdir gemini_python

폴더 이동
cd gemini_python

라이브러리 설치
pip install google-genai python-dotenv

.env 파일 내용
GEMINI_API_KEY=//본인 KEY 값

main.py 실행
python main.py

	//만약 안된다면 
	python -m pip install google-genai python-dotenv
	설치 후 다시 python main.py

web 라이브러리 설치
pip install streamlit google-genai python-dotenv

web 실행
streamlit run app.py
